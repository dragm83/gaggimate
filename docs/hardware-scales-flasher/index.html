GaggiMate Hardware Scales Installer

This page installs the Hardware Scales fork, not official stock GaggiMate firmware.

Connect only the component you intend to flash. The display and controller are both ESP32-S3 devices, so the browser cannot distinguish them automatically. Use a Web Serial-compatible Chromium browser such as Chrome or Edge.

Display

Connect the display USB port with a data-capable cable.

Download display factory image

Controller

Connect the controller USB port with a data-capable cable.

Download controller factory image

Factory installation can erase stored configuration. Back up profiles and settings first. Do not disconnect USB or power while flashing.

Manual flashing

  1. Install Python 3 and run python -m pip install --upgrade esptool.
  2. Download the correct factory image above.
  3. Disconnect the other GaggiMate USB device.
  4. Replace PORT below with the detected serial port. 
python -m esptool --chip esp32s3 --port PORT erase-flash
python -m esptool --chip esp32s3 --port PORT write-flash 0x0 display-complete.bin

Use controller-complete.bin in the second command when flashing the controller. Common ports are /dev/ttyACM0 on Linux, /dev/cu.usbmodem... on macOS, and COM5 on Windows.

If no port appears, hold BOOT while reconnecting USB or pressing RESET, then release BOOT and try again.

Returning to official firmware

The System & Updates page in this fork checks official GaggiMate releases. Installing one replaces the fork on the selected component; update both components when returning to stock. OTA only offers versions newer than the installed version, so use the official release files for equal-version or downgrade recovery.
